Explicacion de la pagina:
Esta página web educativa simula la operación de un sistema de transporte por cable y se divide en cuatro módulos principales:   
Detención de Emergencia:Ingrese la velocidad de la cabina (km/h) y el tiempo de reacción (s).   
Presione "Calcular Distancia" para estimar la distancia recorrida y verificar el umbral didáctico preventivo.   
Mantenimiento:Complete el nombre del componente, horas de uso y el estado operativo.   
Haga clic en "Agregar Registro" para visualizarlo en la tabla dinámica. Puede eliminar registros individuales usando el botón "Eliminar".   
Viento y Oscilación:Ingrese cinco mediciones simuladas de intensidad de viento.   
Haga clic en "Analizar Mediciones" para obtener automáticamente el promedio, el valor máximo y la clasificación descriptiva.   
Sensores:Ingrese el código del sensor respetando estrictamente el formato regulado (SEN-000, ej. SEN-001), el tipo y su lectura numérica.   
El sistema validará la expresión regular y mostrará el registro válido en la tabla.
